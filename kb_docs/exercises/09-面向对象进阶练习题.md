### 题1：继承练习 — 形状类层次（难度：⭐⭐）

**题目**：设计一个形状类的继承体系：

- 基类 `Shape`：
  - 属性：`color`（颜色，默认"白色"）
  - 方法：`area()` — 面积（基类返回 0）
  - 方法：`perimeter()` — 周长（基类返回 0）

- 子类 `Rectangle`（矩形）：
  - 新增属性：`width`、`height`
  - 重写 `area()` 和 `perimeter()`

- 子类 `Circle`（圆形）：
  - 新增属性：`radius`
  - 重写 `area()` 和 `perimeter()`

- 子类 `Square`（正方形），继承自 `Rectangle`：
  - 只有一个边长参数 `side`

**提示**：
- 用 `super().__init__(color)` 调用父类构造
- 圆形面积：π × r²，周长：2 × π × r
- 正方形可以看作长宽相等的矩形

**参考解答**：
```python
import math

class Shape:
    def __init__(self, color="白色"):
        self.color = color
    
    def area(self):
        return 0
    
    def perimeter(self):
        return 0
    
    def __str__(self):
        return f"{self.color}的形状，面积{self.area():.2f}，周长{self.perimeter():.2f}"


class Rectangle(Shape):
    def __init__(self, width, height, color="白色"):
        super().__init__(color)
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)
    
    def __str__(self):
        return f"{self.color}的矩形，{self.width}×{self.height}，面积{self.area():.2f}，周长{self.perimeter():.2f}"


class Circle(Shape):
    def __init__(self, radius, color="白色"):
        super().__init__(color)
        self.radius = radius
    
    def area(self):
        return math.pi * self.radius ** 2
    
    def perimeter(self):
        return 2 * math.pi * self.radius
    
    def __str__(self):
        return f"{self.color}的圆形，半径{self.radius}，面积{self.area():.2f}，周长{self.perimeter():.2f}"


class Square(Rectangle):
    def __init__(self, side, color="白色"):
        super().__init__(side, side, color)
    
    def __str__(self):
        return f"{self.color}的正方形，边长{self.width}，面积{self.area():.2f}，周长{self.perimeter():.2f}"


# 测试
shapes = [
    Rectangle(3, 4, "红色"),
    Circle(5, "蓝色"),
    Square(6, "绿色"),
]

for s in shapes:
    print(s)

# 多态：计算总面积
total_area = sum(s.area() for s in shapes)
print(f"\n所有形状的总面积：{total_area:.2f}")
```

### 题2：魔术方法 — 自定义向量类（难度：⭐⭐）

**题目**：实现一个 `Vector` 二维向量类，支持以下操作：
- 加法：`v1 + v2`
- 减法：`v1 - v2`
- 数乘：`v * 3`
- 相等比较：`v1 == v2`（x和y都相等）
- 字符串表示：`str(v)` 返回 "(x, y)"
- `len()` 返回向量的模长（取整）

**提示**：
- 加法对应 `__add__`
- 减法对应 `__sub__`
- 数乘对应 `__mul__`
- 相等对应 `__eq__`
- 字符串对应 `__str__`
- len 对应 `__len__`（注意返回整数）

**参考解答**：
```python
import math

class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    def __sub__(self, other):
        return Vector(self.x - other.x, self.y - other.y)
    
    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)
    
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
    
    def __str__(self):
        return f"({self.x}, {self.y})"
    
    def __len__(self):
        return int(math.sqrt(self.x ** 2 + self.y ** 2))
    
    def magnitude(self):
        """精确的模长"""
        return math.sqrt(self.x ** 2 + self.y ** 2)


# 测试
v1 = Vector(1, 2)
v2 = Vector(3, 4)

print("v1 =", v1)          # (1, 2)
print("v2 =", v2)          # (3, 4)
print("v1 + v2 =", v1 + v2)  # (4, 6)
print("v1 - v2 =", v1 - v2)  # (-2, -2)
print("v1 * 3 =", v1 * 3)    # (3, 6)
print("v1 == Vector(1,2):", v1 == Vector(1, 2))  # True
print("len(v2):", len(v2))    # 5（模长5，取整）
print("v2 的模长：", v2.magnitude())  # 5.0
```

### 题3：@property 装饰器（难度：⭐⭐）

**题目**：实现一个 `Temperature` 温度类：
- 属性：`celsius`（摄氏度）
- 使用 `@property` 定义 `fahrenheit`（华氏度），可以读取和设置
  - 读取时：根据摄氏度计算华氏度
  - 设置时：根据华氏度反推摄氏度
- 公式：`F = C × 9/5 + 32`，`C = (F - 32) × 5/9`
- 限制：摄氏度不能低于 -273.15（绝对零度）

**提示**：
- `@property` 定义 getter
- `@fahrenheit.setter` 定义 setter
- 在 setter 中做验证

**参考解答**：
```python
class Temperature:
    ABSOLUTE_ZERO = -273.15
    
    def __init__(self, celsius=0):
        self.celsius = max(celsius, self.ABSOLUTE_ZERO)
    
    @property
    def celsius(self):
        return self._celsius
    
    @celsius.setter
    def celsius(self, value):
        if value < self.ABSOLUTE_ZERO:
            raise ValueError(f"温度不能低于绝对零度 {self.ABSOLUTE_ZERO}°C")
        self._celsius = value
    
    @property
    def fahrenheit(self):
        """华氏度"""
        return self._celsius * 9 / 5 + 32
    
    @fahrenheit.setter
    def fahrenheit(self, value):
        celsius = (value - 32) * 5 / 9
        self.celsius = celsius  # 复用 celsius 的验证
    
    def __str__(self):
        return f"{self.celsius:.2f}°C = {self.fahrenheit:.2f}°F"


# 测试
t = Temperature(25)
print(t)                          # 25.00°C = 77.00°F

t.fahrenheit = 100
print(t)                          # 37.78°C = 100.00°F
print("摄氏度：", t.celsius)       # 37.777...
print("华氏度：", t.fahrenheit)    # 100.0

t.celsius = 0
print(t)                          # 0.00°C = 32.00°F

try:
    t.celsius = -300  # 低于绝对零度
except ValueError as e:
    print("错误：", e)
```

### 题4：多态 — 员工工资计算（难度：⭐⭐⭐）

**题目**：设计一个员工工资计算系统：

- 基类 `Employee`：
  - 属性：`name`（姓名）
  - 方法：`calculate_salary()` — 计算工资（基类返回 0）

- 子类 `FullTimeEmployee`（全职员工）：
  - 属性：`monthly_salary`（月薪）
  - 工资 = 月薪

- 子类 `PartTimeEmployee`（兼职员工）：
  - 属性：`hourly_wage`（时薪）、`hours_worked`（工作小时数）
  - 工资 = 时薪 × 工作小时数

- 子类 `SalesEmployee`（销售员工）：
  - 属性：`base_salary`（底薪）、`sales`（销售额）、`commission_rate`（提成比例）
  - 工资 = 底薪 + 销售额 × 提成比例

最后写一个函数 `print_payroll(employees)`，打印所有员工的工资。

**提示**：
- 每个子类重写 `calculate_salary()`
- `print_payroll` 函数接收员工列表，不用判断类型，直接调用方法

**参考解答**：
```python
class Employee:
    def __init__(self, name):
        self.name = name
    
    def calculate_salary(self):
        return 0
    
    def __str__(self):
        return f"{self.name} - 工资：{self.calculate_salary()} 元"


class FullTimeEmployee(Employee):
    def __init__(self, name, monthly_salary):
        super().__init__(name)
        self.monthly_salary = monthly_salary
    
    def calculate_salary(self):
        return self.monthly_salary


class PartTimeEmployee(Employee):
    def __init__(self, name, hourly_wage, hours_worked):
        super().__init__(name)
        self.hourly_wage = hourly_wage
        self.hours_worked = hours_worked
    
    def calculate_salary(self):
        return self.hourly_wage * self.hours_worked


class SalesEmployee(Employee):
    def __init__(self, name, base_salary, sales, commission_rate=0.05):
        super().__init__(name)
        self.base_salary = base_salary
        self.sales = sales
        self.commission_rate = commission_rate
    
    def calculate_salary(self):
        return self.base_salary + self.sales * self.commission_rate


def print_payroll(employees):
    print("===== 工资单 =====")
    total = 0
    for emp in employees:
        salary = emp.calculate_salary()
        print(f"{emp.name}：{salary:.2f} 元")
        total += salary
    print(f"工资总额：{total:.2f} 元")
    print("=" * 20)


# 测试
employees = [
    FullTimeEmployee("张三", 8000),
    PartTimeEmployee("李四", 50, 80),
    SalesEmployee("王五", 5000, 50000, 0.05),
    SalesEmployee("赵六", 6000, 100000, 0.08),
]

print_payroll(employees)
```

### 题5：单例模式（难度：⭐⭐⭐）

**题目**：实现一个单例模式的 `AppConfig` 配置类：
- 整个程序中只有一个实例
- 支持从字典加载配置
- 支持通过属性方式访问配置项
- 第二次创建实例时返回同一个对象

**提示**：
- 重写 `__new__` 方法控制实例创建
- 用类属性 `_instance` 保存唯一实例
- 可以用 `__getattr__` 或直接存字典

**参考解答**：
```python
import json

class AppConfig:
    _instance = None
    _initialized = False
    
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self, config_dict=None):
        if AppConfig._initialized:
            return  # 已经初始化过了，不再初始化
        self._config = {}
        if config_dict:
            self._config.update(config_dict)
        AppConfig._initialized = True
    
    def get(self, key, default=None):
        return self._config.get(key, default)
    
    def set(self, key, value):
        self._config[key] = value
    
    def load_from_file(self, filename):
        with open(filename, "r", encoding="utf-8") as f:
            self._config.update(json.load(f))
    
    def __getattr__(self, name):
        """让配置可以用 . 属性访问"""
        if name.startswith("_"):
            raise AttributeError(name)
        return self._config.get(name)
    
    def __str__(self):
        return f"AppConfig({self._config})"


# 测试
config1 = AppConfig({
    "app_name": "学习规划助手",
    "version": "1.0.0",
    "debug": True,
    "database": {
        "host": "localhost",
        "port": 3306
    }
})

config2 = AppConfig()  # 第二次创建

print("config1 is config2:", config1 is config2)  # True，同一个实例
print("应用名：", config1.app_name)                 # 学习规划助手
print("版本：", config1.version)                   # 1.0.0
print("调试模式：", config1.get("debug"))          # True

config2.set("version", "1.1.0")                    # 通过 config2 修改
print("config1 的版本：", config1.version)          # 1.1.0，config1 也变了（同一个实例）
```
