# 第一章：基础语法练习题

## 题目

### 题1：变量赋值与打印（难度：⭐）

**题目**：创建一个变量 `name` 存储你的名字，一个变量 `age` 存储你的年龄，然后用 `print()` 输出"我叫XXX，今年XX岁"。

**提示**：
- 字符串可以用单引号或双引号
- 数字不需要引号
- `print()` 中可以用逗号分隔多个内容

**参考解答**：
```python
name = "张三"
age = 20
print("我叫", name, "，今年", age, "岁")
```

### 题2：数据类型判断（难度：⭐⭐）

**题目**：给定以下变量，分别用 `type()` 函数判断它们的数据类型，并打印出来：
- `a = 100`
- `b = 3.14`
- `c = "Hello"`
- `d = True`
- `e = None`

**提示**：type() 函数返回的是类型对象，可以直接打印

**参考解答**：
```python
a = 100
b = 3.14
c = "Hello"
d = True
e = None

print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>
print(type(e))  # <class 'NoneType'>
```

### 题3：类型转换（难度：⭐⭐）

**题目**：从用户输入获取两个数字字符串，将它们转换为整数后相加，输出结果。

示例运行：
```
请输入第一个数字：10
请输入第二个数字：20
两数之和为：30
```

**提示**：
- `input()` 返回的是字符串
- 用 `int()` 函数将字符串转为整数
- 加法用 `+` 运算符

**参考解答**：
```python
num1 = input("请输入第一个数字：")
num2 = input("请输入第二个数字：")
result = int(num1) + int(num2)
print("两数之和为：", result)
```

### 题4：字符串拼接与格式化（难度：⭐⭐）

**题目**：用户输入姓名和城市，用三种不同的方式输出"你好，我是XXX，来自XXX"：
1. 用 `+` 拼接字符串
2. 用 `,` 分隔多个参数
3. 用 f-string（格式化字符串）

**提示**：
- f-string 格式：`f"文字{变量}文字"`
- 用 `+` 拼接时，数字需要先转字符串

**参考解答**：
```python
name = input("请输入你的姓名：")
city = input("请输入你来自的城市：")

# 方式1：+ 拼接
print("你好，我是" + name + "，来自" + city)

# 方式2：, 分隔
print("你好，我是", name, "，来自", city)

# 方式3：f-string
print(f"你好，我是{name}，来自{city}")
```

### 题5：简单计算（难度：⭐⭐⭐）

**题目**：输入圆的半径，计算圆的面积和周长，并保留两位小数输出。
- 面积公式：π × r²
- 周长公式：2 × π × r
- π 取 3.14159

示例：
```
请输入圆的半径：5
圆的面积为：78.54
圆的周长为：31.42
```

**提示**：
- 平方用 `** 2`
- 保留两位小数可以用 `round(数值, 2)` 或 f-string 的 `:.2f`

**参考解答**：
```python
pi = 3.14159
r = float(input("请输入圆的半径："))

area = pi * r ** 2
perimeter = 2 * pi * r

print(f"圆的面积为：{area:.2f}")
print(f"圆的周长为：{perimeter:.2f}")
```
