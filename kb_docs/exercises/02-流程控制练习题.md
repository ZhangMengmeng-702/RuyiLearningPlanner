### 题1：成绩等级判断（难度：⭐）

**题目**：输入一个 0-100 的分数，根据分数输出等级：
- 90分及以上：A
- 80-89分：B
- 70-79分：C
- 60-69分：D
- 60分以下：不及格

**提示**：用 `if-elif-else` 多分支判断

**参考解答**：
```python
score = int(input("请输入分数："))

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("不及格")
```

### 题2：累加求和（难度：⭐⭐）

**题目**：计算 1+2+3+...+100 的和，分别用 `for` 循环和 `while` 循环实现。

**提示**：
- 用一个变量 `sum_val` 保存累加结果，初始为 0
- for 循环用 `range(1, 101)`
- while 循环需要自己维护计数器

**参考解答**：
```python
# for 循环实现
sum_val = 0
for i in range(1, 101):
    sum_val += i
print("for循环结果：", sum_val)

# while 循环实现
sum_val = 0
i = 1
while i <= 100:
    sum_val += i
    i += 1
print("while循环结果：", sum_val)
```

### 题3：猜数字游戏（难度：⭐⭐）

**题目**：程序随机生成一个 1-100 的整数，用户有最多 7 次机会猜数字。每次猜错，提示"大了"或"小了"，猜对则输出"恭喜你，猜对了！"，7次都没猜对则输出"游戏结束，答案是XX"。

**提示**：
- 生成随机数：`import random`，`num = random.randint(1, 100)`
- 用 `for _ in range(7)` 控制次数

**参考解答**：
```python
import random

answer = random.randint(1, 100)
print("我想了一个 1-100 之间的数字，你有 7 次机会猜")

for i in range(7):
    guess = int(input(f"第 {i+1} 次猜："))
    if guess == answer:
        print("恭喜你，猜对了！")
        break
    elif guess > answer:
        print("大了")
    else:
        print("小了")
else:
    print(f"游戏结束，答案是 {answer}")
```

### 题4：九九乘法表（难度：⭐⭐）

**题目**：用嵌套循环打印九九乘法表。

输出样式：
```
1×1=1
1×2=2  2×2=4
1×3=3  2×3=6  3×3=9
...
```

**提示**：
- 外层循环控制行数（1-9）
- 内层循环控制每行的式子（1到当前行数）
- 用 `end='\t'` 让同一行不换行，用制表符分隔

**参考解答**：
```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={j*i}", end="\t")
    print()
```

### 题5：打印菱形（难度：⭐⭐⭐）

**题目**：输入一个奇数 n，打印高度为 n 的菱形。

例如输入 5：
```
  *
 ***
*****
 ***
  *
```

**提示**：
- 菱形可以分成上半部分（递增）和下半部分（递减）
- 每行先打印空格，再打印星号
- 上半部分从 1 到 n，步长为 2
- 下半部分从 n-2 到 1，步长为 -2

**参考解答**：
```python
n = int(input("请输入一个奇数："))

# 上半部分
for i in range(1, n + 1, 2):
    spaces = (n - i) // 2
    print(" " * spaces + "*" * i)

# 下半部分
for i in range(n - 2, 0, -2):
    spaces = (n - i) // 2
    print(" " * spaces + "*" * i)
```
