### 题1：定义一个简单的类（难度：⭐）

**题目**：定义一个 `Person` 类：
- 属性：`name`（姓名）、`age`（年龄）
- 方法：`introduce()` — 打印 "大家好，我叫XXX，今年XX岁"
- 创建两个对象并调用 `introduce()` 方法

**提示**：
- 构造方法：`__init__(self, name, age)`
- 属性赋值：`self.name = name`

**参考解答**：
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def introduce(self):
        print(f"大家好，我叫{self.name}，今年{self.age}岁")

p1 = Person("张三", 20)
p2 = Person("李四", 22)

p1.introduce()  # 大家好，我叫张三，今年20岁
p2.introduce()  # 大家好，我叫李四，今年22岁
```

### 题2：计数器类（难度：⭐⭐）

**题目**：设计一个 `Counter` 计数器类：
- 属性：`count`（当前计数，初始为 0）
- 方法：
  - `increment()` — 计数加 1
  - `decrement()` — 计数减 1
  - `reset()` — 归零
  - `get_count()` — 获取当前计数值
- 要求：`count` 不能为负数（减到 0 就不能再减了）

**提示**：
- 用私有属性 `__count` 封装
- decrement 时判断如果已经是 0 就不减了

**参考解答**：
```python
class Counter:
    def __init__(self):
        self.__count = 0
    
    def increment(self):
        self.__count += 1
    
    def decrement(self):
        if self.__count > 0:
            self.__count -= 1
        else:
            print("计数已经是 0 了，不能再减了")
    
    def reset(self):
        self.__count = 0
    
    def get_count(self):
        return self.__count

# 测试
c = Counter()
print("初始：", c.get_count())  # 0

c.increment()
c.increment()
c.increment()
print("加3次后：", c.get_count())  # 3

c.decrement()
print("减1次后：", c.get_count())  # 2

c.reset()
print("归零后：", c.get_count())  # 0

c.decrement()  # 计数已经是 0 了，不能再减了
```

### 题3：学生成绩管理（难度：⭐⭐）

**题目**：设计一个 `Student` 类：
- 属性：`name`（姓名）、`__scores`（私有，成绩字典，如 {"语文": 85, "数学": 92}）
- 方法：
  - `set_score(subject, score)` — 设置某科成绩（0-100分才有效）
  - `get_score(subject)` — 获取某科成绩
  - `get_average()` — 计算平均分
  - `get_total()` — 计算总分
  - `print_report()` — 打印成绩单

**提示**：
- 成绩验证：0 <= score <= 100
- 平均分 = 总分 / 科目数

**参考解答**：
```python
class Student:
    def __init__(self, name):
        self.name = name
        self.__scores = {}
    
    def set_score(self, subject, score):
        if 0 <= score <= 100:
            self.__scores[subject] = score
        else:
            print(f"分数 {score} 无效，必须在 0-100 之间")
    
    def get_score(self, subject):
        return self.__scores.get(subject, "无此科目")
    
    def get_average(self):
        if not self.__scores:
            return 0
        return sum(self.__scores.values()) / len(self.__scores)
    
    def get_total(self):
        return sum(self.__scores.values())
    
    def print_report(self):
        print(f"===== {self.name} 的成绩单 =====")
        for subject, score in self.__scores.items():
            print(f"  {subject}：{score} 分")
        print(f"  总分：{self.get_total()} 分")
        print(f"  平均分：{self.get_average():.1f} 分")
        print("=" * 30)

# 测试
s = Student("张三")
s.set_score("语文", 85)
s.set_score("数学", 92)
s.set_score("英语", 78)
s.set_score("体育", 120)  # 无效

s.print_report()
print("数学成绩：", s.get_score("数学"))
print("化学成绩：", s.get_score("化学"))
```

### 题4：类属性和类方法（难度：⭐⭐）

**题目**：设计一个 `Employee` 员工类：
- 类属性：`company = "ABC公司"`、`total_count = 0`（员工总数）
- 实例属性：`name`、`salary`
- 类方法：`get_total_count()` — 返回员工总数
- 实例方法：`get_info()` — 返回员工信息字符串
- 要求：每创建一个员工，`total_count` 就加 1

**提示**：
- 类属性直接在类里面定义
- 类方法用 `@classmethod` 装饰器，第一个参数是 `cls`
- 在 `__init__` 里让 `cls.total_count += 1`（要用 `Employee.total_count`）

**参考解答**：
```python
class Employee:
    company = "ABC公司"
    total_count = 0
    
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
        Employee.total_count += 1  # 每创建一个，总数+1
    
    def get_info(self):
        return f"[{Employee.company}] {self.name}，月薪：{self.salary} 元"
    
    @classmethod
    def get_total_count(cls):
        return cls.total_count

# 测试
e1 = Employee("张三", 8000)
e2 = Employee("李四", 9000)
e3 = Employee("王五", 7500)

print(e1.get_info())
print(e2.get_info())
print(e3.get_info())
print("员工总数：", Employee.get_total_count())  # 3
print("员工总数：", Employee.total_count)        # 3
```

### 题5：矩形类（难度：⭐⭐⭐）

**题目**：设计一个 `Rectangle` 矩形类：
- 属性：`width`（宽度）、`height`（高度）
- 方法：
  - `area()` — 计算面积
  - `perimeter()` — 计算周长
  - `is_square()` — 判断是否为正方形
  - `__str__()` — 返回字符串表示，如 "Rectangle(3, 4)"
- 要求：宽度和高度必须为正数，否则设置为 1

**提示**：
- 在 `__init__` 中验证宽高
- `__str__` 是魔术方法，`print(对象)` 时会自动调用

**参考解答**：
```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width if width > 0 else 1
        self.height = height if height > 0 else 1
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)
    
    def is_square(self):
        return self.width == self.height
    
    def __str__(self):
        return f"Rectangle({self.width}, {self.height})"

# 测试
r1 = Rectangle(3, 4)
print(r1)                    # Rectangle(3, 4)
print("面积：", r1.area())    # 12
print("周长：", r1.perimeter())  # 14
print("是正方形吗：", r1.is_square())  # False

r2 = Rectangle(5, 5)
print(r2)                    # Rectangle(5, 5)
print("是正方形吗：", r2.is_square())  # True

r3 = Rectangle(-2, 6)
print(r3)                    # Rectangle(1, 6)
```
