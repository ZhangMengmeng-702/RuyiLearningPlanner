### 题1：文件写入与读取（难度：⭐）

**题目**：
1. 创建一个文件 `names.txt`，写入 5 个名字，每行一个
2. 读取这个文件，打印出所有名字
3. 统计文件中有多少行

**提示**：
- 写入模式：`open("file.txt", "w")`
- 读取模式：`open("file.txt", "r")`
- 推荐用 `with` 语句自动关闭文件
- 读取所有行：`f.readlines()`

**参考解答**：
```python
# 写入文件
with open("names.txt", "w", encoding="utf-8") as f:
    f.write("张三\n")
    f.write("李四\n")
    f.write("王五\n")
    f.write("赵六\n")
    f.write("钱七\n")

# 读取文件
with open("names.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print("所有名字：")
    for line in lines:
        print(line.strip())  # strip() 去掉换行符

print("总行数：", len(lines))
```

### 题2：复制文件（难度：⭐⭐）

**题目**：写一个函数 `copy_file(src, dst)`，将 src 文件的内容复制到 dst 文件中。要求：
- 如果 src 文件不存在，捕获异常并打印提示
- 用 `with` 语句确保文件正确关闭

**提示**：
- 用 `try-except FileNotFoundError` 捕获文件不存在异常
- 读取全部内容后写入目标文件

**参考解答**：
```python
def copy_file(src, dst):
    try:
        with open(src, "r", encoding="utf-8") as f_src:
            content = f_src.read()
        with open(dst, "w", encoding="utf-8") as f_dst:
            f_dst.write(content)
        print(f"已将 {src} 复制到 {dst}")
    except FileNotFoundError:
        print(f"错误：文件 {src} 不存在")

# 测试
copy_file("names.txt", "names_copy.txt")
copy_file("nonexistent.txt", "test.txt")
```

### 题3：CSV 数据统计（难度：⭐⭐）

**题目**：有一个成绩文件 `scores.csv`，内容如下：
```
姓名,语文,数学,英语
张三,85,92,78
李四,90,88,95
王五,76,85,80
赵六,88,79,92
```
编写程序：
1. 读取这个 CSV 文件
2. 计算每个学生的总分和平均分
3. 找出总分最高的学生

**提示**：
- 用 `split(",")` 分割每行
- 跳过第一行（表头）
- 注意数字是字符串，需要用 `int()` 转换

**参考解答**：
```python
students = []

with open("scores.csv", "r", encoding="utf-8") as f:
    lines = f.readlines()
    header = lines[0].strip()  # 跳过表头
    for line in lines[1:]:
        parts = line.strip().split(",")
        name = parts[0]
        scores = [int(x) for x in parts[1:]]
        total = sum(scores)
        avg = total / len(scores)
        students.append({
            "name": name,
            "scores": scores,
            "total": total,
            "avg": avg
        })

# 打印结果
for s in students:
    print(f"{s['name']}: 总分={s['total']}, 平均分={s['avg']:.1f}")

# 找出最高分
top = max(students, key=lambda x: x["total"])
print(f"\n总分最高：{top['name']}（{top['total']}分）")
```

### 题4：异常处理练习（难度：⭐⭐）

**题目**：写一个函数 `safe_divide(a, b)`，实现安全的除法：
- 如果 b 为 0，捕获 ZeroDivisionError，返回 None 并打印"除数不能为零"
- 如果 a 或 b 不是数字，捕获 TypeError，返回 None 并打印"参数类型错误"
- 正常情况下返回 a / b 的结果

**提示**：可以用多个 `except` 分支捕获不同类型的异常

**参考解答**：
```python
def safe_divide(a, b):
    try:
        result = a / b
        return result
    except ZeroDivisionError:
        print("错误：除数不能为零")
        return None
    except TypeError:
        print("错误：参数类型错误")
        return None

# 测试
print(safe_divide(10, 2))      # 5.0
print(safe_divide(10, 0))      # None + 错误提示
print(safe_divide("10", 2))    # None + 错误提示
```

### 题5：日记本程序（难度：⭐⭐⭐）

**题目**：实现一个简单的日记本程序，功能如下：
1. 程序启动时，提示用户输入今天的日记内容
2. 将日记内容追加写入 `diary.txt`，前面带上日期时间
3. 如果文件不存在，自动创建
4. 如果用户输入 "quit"，则退出程序
5. 提供查看全部日记的选项

**提示**：
- 追加模式：`open("diary.txt", "a")`
- 获取当前时间：`from datetime import datetime`，`datetime.now().strftime("%Y-%m-%d %H:%M:%S")`

**参考解答**：
```python
from datetime import datetime

def add_diary():
    content = input("请输入今天的日记内容（输入 quit 退出）：")
    if content.lower() == "quit":
        return False
    
    now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    with open("diary.txt", "a", encoding="utf-8") as f:
        f.write(f"[{now}]\n{content}\n\n")
    print("日记已保存！")
    return True

def show_diary():
    try:
        with open("diary.txt", "r", encoding="utf-8") as f:
            content = f.read()
            if content:
                print("\n===== 全部日记 =====")
                print(content)
            else:
                print("还没有日记哦")
    except FileNotFoundError:
        print("还没有日记哦")

# 主程序
while True:
    print("\n===== 我的日记本 =====")
    print("1. 写日记")
    print("2. 查看日记")
    print("3. 退出")
    choice = input("请选择：")
    
    if choice == "1":
        add_diary()
    elif choice == "2":
        show_diary()
    elif choice == "3":
        print("再见！")
        break
    else:
        print("无效选择")
```
