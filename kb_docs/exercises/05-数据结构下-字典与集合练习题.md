## 题目

### 题1：字典基本操作（难度：⭐⭐）

**题目**：有一个学生信息字典：
```python
student = {
    "name": "张三",
    "age": 20,
    "major": "计算机科学",
    "scores": {"语文": 85, "数学": 92, "英语": 78}
}
```
完成以下操作：
1. 打印学生姓名
2. 添加性别字段 "gender": "男"
3. 修改年龄为 21
4. 打印所有科目名称（keys）
5. 打印所有分数（values）
6. 计算平均分

**提示**：
- 字典访问：`dict["key"]` 或 `dict.get("key")`
- 添加/修改：`dict["key"] = value`
- 所有键：`dict.keys()`，所有值：`dict.values()`

**参考解答**：
```python
student = {
    "name": "张三",
    "age": 20,
    "major": "计算机科学",
    "scores": {"语文": 85, "数学": 92, "英语": 78}
}

# 1. 打印姓名
print("姓名：", student["name"])

# 2. 添加性别
student["gender"] = "男"
print("添加性别后：", student)

# 3. 修改年龄
student["age"] = 21
print("修改年龄后：", student)

# 4. 所有科目
scores = student["scores"]
print("所有科目：", list(scores.keys()))

# 5. 所有分数
print("所有分数：", list(scores.values()))

# 6. 平均分
avg = sum(scores.values()) / len(scores)
print("平均分：", avg)
```

### 题2：集合运算（难度：⭐⭐）

**题目**：有两个班级的学生名单：
```python
class_a = {"张三", "李四", "王五", "赵六", "钱七"}
class_b = {"王五", "赵六", "孙八", "周九", "吴十"}
```
求：
1. 两个班都有的人（交集）
2. 至少在一个班的人（并集）
3. 只在 A 班不在 B 班的人（差集）
4. 只在一个班的人（对称差集）

**提示**：
- 交集：`&` 或 `intersection()`
- 并集：`|` 或 `union()`
- 差集：`-` 或 `difference()`
- 对称差集：`^` 或 `symmetric_difference()`

**参考解答**：
```python
class_a = {"张三", "李四", "王五", "赵六", "钱七"}
class_b = {"王五", "赵六", "孙八", "周九", "吴十"}

print("两个班都有：", class_a & class_b)
print("至少一个班：", class_a | class_b)
print("只在A班：", class_a - class_b)
print("只在一个班：", class_a ^ class_b)
```

### 题3：字典推导式（难度：⭐⭐）

**题目**：用字典推导式完成以下任务：
1. 将两个列表 `["a", "b", "c"] 和 [1, 2, 3] 组合成字典
2. 给定字典 `{"a": 1, "b": 2, "c": 3}`，生成值乘以 2 的新字典
3. 从字典 `{"apple": 5, "banana": 3, "orange": 8, "grape": 1}` 中筛选出值大于 3 的项
4. 将字典的键和值互换（假设值都是唯一的）

**提示**：
- 字典推导式格式：`{键表达式: 值表达式 for 变量 in 可迭代对象 if 条件}`
- `zip()` 函数可以同时遍历两个列表

**参考解答**：
```python
# 1. 两个列表组合成字典
keys = ["a", "b", "c"]
values = [1, 2, 3]
d1 = {k: v for k, v in zip(keys, values)}
print(d1)  # {'a': 1, 'b': 2, 'c': 3}

# 2. 值乘以2
d2 = {"a": 1, "b": 2, "c": 3}
d2_doubled = {k: v * 2 for k, v in d2.items()}
print(d2_doubled)  # {'a': 2, 'b': 4, 'c': 6}

# 3. 筛选值大于3的
d3 = {"apple": 5, "banana": 3, "orange": 8, "grape": 1}
d3_filtered = {k: v for k, v in d3.items() if v > 3}
print(d3_filtered)  # {'apple': 5, 'orange': 8}

# 4. 键值互换
d4 = {"a": 1, "b": 2, "c": 3}
d4_swapped = {v: k for k, v in d4.items()}
print(d4_swapped)  # {1: 'a', 2: 'b', 3: 'c'}
```

### 题4：词频统计（难度：⭐⭐⭐）

**题目**：写一个函数 `count_words(text)`，统计一段文本中每个单词出现的次数，返回字典。不区分大小写，忽略标点符号。

示例：
```python
text = "Hello world hello Python python WORLD"
print(count_words(text))
# 输出: {'hello': 2, 'world': 2, 'python': 2}
```

**提示**：
- `text.lower()` 转小写
- 可以用 `str.split()` 分割单词
- 用字典累加：如果 key 不存在初始化为 0，再加 1

**参考解答**：
```python
def count_words(text):
    # 转小写，分割
    words = text.lower().split()
    # 清理标点（简单处理）
    words = [w.strip(".,!?;:\"'") for w in words]
    
    result = {}
    for w in words:
        if w:  # 跳过空字符串
            result[w] = result.get(w, 0) + 1
    return result

text = "Hello world hello Python python WORLD"
print(count_words(text))
```

### 题5：找重复元素（难度：⭐⭐⭐）

**题目**：写一个函数 `find_duplicates(lst)`，找出列表中所有重复出现的元素，返回一个集合。

示例：
```python
nums = [1, 2, 3, 2, 4, 3, 5, 1, 6]
print(find_duplicates(nums))  # {1, 2, 3}
```

**提示**：
- 用一个集合记录已经出现过的元素
- 用另一个集合记录重复的元素
- 遍历列表，如果元素已经在见过的集合里，就加到重复集合里

**参考解答**：
```python
def find_duplicates(lst):
    seen = set()
    duplicates = set()
    
    for item in lst:
        if item in seen:
            duplicates.add(item)
        else:
            seen.add(item)
    
    return duplicates

# 测试
nums = [1, 2, 3, 2, 4, 3, 5, 1, 6]
print("重复元素：", find_duplicates(nums))

# 测试字符串
words = ["apple", "banana", "apple", "orange", "banana", "grape"]
print("重复单词：", find_duplicates(words))
```
