### 题1：判断素数函数（难度：⭐⭐）

**题目**：写一个函数 `is_prime(n)`，判断 n 是否为素数，返回 True 或 False。然后用这个函数找出 100 以内的所有素数。

**提示**：
- 素数只能被 1 和它本身整除
- 从 2 到 sqrt(n) 检查是否有因子即可

**参考解答**：
```python
import math

def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

# 找出 100 以内所有素数
primes = []
for i in range(2, 101):
    if is_prime(i):
        primes.append(i)
print("100以内的素数：", primes)
```

### 题2：阶乘函数（难度：⭐⭐）

**题目**：写一个函数 `factorial(n)`，返回 n 的阶乘（n! = 1×2×3×...×n）。分别用循环和递归两种方式实现。

**提示**：
- 0! = 1，1! = 1
- 递归：函数自己调用自己，注意要有终止条件

**参考解答**：
```python
# 循环实现
def factorial_loop(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

# 递归实现
def factorial_recursive(n):
    if n <= 1:
        return 1
    return n * factorial_recursive(n - 1)

print("5! =", factorial_loop(5))
print("5! =", factorial_recursive(5))
```

### 题3：默认参数与关键字参数（难度：⭐⭐）

**题目**：写一个函数 `greet(name, greeting="你好", punctuation="!")`，返回问候语字符串。
- 只传 name：返回 "你好，张三!"
- 传 name 和 greeting：返回 "早上好，张三!"
- 三个参数都传：返回 "早上好，张三。"

**提示**：
- 默认参数放在参数列表最后
- 调用时可以用 `参数名=值` 的方式指定

**参考解答**：
```python
def greet(name, greeting="你好", punctuation="!"):
    return f"{greeting}，{name}{punctuation}"

print(greet("张三"))                          # 你好，张三!
print(greet("李四", "早上好"))                 # 早上好，李四!
print(greet("王五", punctuation="。"))         # 你好，王五。
print(greet("赵六", punctuation="~", greeting="嗨"))  # 嗨，赵六~
```

### 题4：可变参数求和（难度：⭐⭐⭐）

**题目**：写一个函数 `sum_all(*args)`，可以接收任意多个数字参数，返回它们的和。
额外要求：再写一个函数 `average(*args)`，返回平均值。

**提示**：
- `*args` 可以接收任意多个位置参数，在函数内是一个元组
- 平均值 = 总和 / 参数个数

**参考解答**：
```python
def sum_all(*args):
    total = 0
    for num in args:
        total += num
    return total

def average(*args):
    if len(args) == 0:
        return 0
    return sum_all(*args) / len(args)

print(sum_all(1, 2, 3))              # 6
print(sum_all(1, 2, 3, 4, 5))        # 15
print(average(1, 2, 3, 4, 5))        # 3.0
```

### 题5：作用域练习（难度：⭐⭐⭐）

**题目**：阅读以下代码，写出运行结果，并解释为什么。然后自己编写一个类似的作用域练习：
- 全局变量、局部变量的区别
- `global` 关键字的用法
- 嵌套函数中的变量访问

```python
x = 10

def func1():
    x = 20
    print("func1内部x =", x)

def func2():
    global x
    x = 30
    print("func2内部x =", x)

func1()
print("func1后x =", x)
func2()
print("func2后x =", x)
```

**提示**：
- 函数内部直接赋值的变量是局部变量
- 用 `global` 声明后可以修改全局变量
- 只读访问全局变量不需要 `global`

**参考解答**：
```python
x = 10

def func1():
    x = 20  # 局部变量，不影响全局
    print("func1内部x =", x)

def func2():
    global x  # 声明使用全局变量
    x = 30
    print("func2内部x =", x)

func1()          # 输出：func1内部x = 20
print("func1后x =", x)  # 输出：func1后x = 10（全局变量没变）
func2()          # 输出：func2内部x = 30
print("func2后x =", x)  # 输出：func2后x = 30（全局变量被修改）
```
