## 一、日期时间 — datetime 模块

### 1.1 获取当前时间

```python
from datetime import datetime, date, time, timedelta

# 当前日期时间
now = datetime.now()
print(now)                # 2024-01-15 14:30:00.123456
print(now.year)           # 2024
print(now.month)          # 1
print(now.day)            # 15
print(now.hour)           # 14
print(now.minute)         # 30
print(now.second)         # 0

# 今天的日期
today = date.today()
print(today)              # 2024-01-15
```

### 1.2 创建指定的日期时间

```python
# 指定日期
d = date(2024, 1, 1)
print(d)  # 2024-01-01

# 指定日期时间
dt = datetime(2024, 1, 1, 12, 30, 0)
print(dt)  # 2024-01-01 12:30:00
```

### 1.3 格式化输出

```python
now = datetime.now()

# datetime → 字符串
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # 2024-01-15 14:30:00
print(now.strftime("%Y年%m月%d日"))        # 2024年01月15日

# 字符串 → datetime
s = "2024-01-15 14:30:00"
dt = datetime.strptime(s, "%Y-%m-%d %H:%M:%S")
print(dt)
```

常用格式符：
| 格式符 | 含义 | 示例 |
|--------|------|------|
| `%Y` | 4位年份 | 2024 |
| `%m` | 月份（01-12） | 01 |
| `%d` | 日期（01-31） | 15 |
| `%H` | 小时（00-23） | 14 |
| `%M` | 分钟（00-59） | 30 |
| `%S` | 秒（00-59） | 00 |
| `%A` | 星期几 | Monday |

### 1.4 时间差 — timedelta

```python
from datetime import datetime, timedelta

now = datetime.now()

# 10天后
future = now + timedelta(days=10)
print(future)

# 2小时前
past = now - timedelta(hours=2)
print(past)

# 计算两个日期相差多少天
d1 = date(2024, 1, 1)
d2 = date(2024, 2, 1)
diff = d2 - d1
print(diff.days)  # 31
```

## 二、系统操作 — os 模块

### 2.1 文件和目录操作

```python
import os

# 获取当前工作目录
print(os.getcwd())

# 切换目录
os.chdir("d:/test")

# 列出目录内容
print(os.listdir("."))           # 列出当前目录
print(os.listdir("d:/test"))     # 列出指定目录

# 创建目录
os.mkdir("new_dir")              # 创建单级目录
os.makedirs("a/b/c")             # 创建多级目录

# 删除
os.rmdir("empty_dir")            # 删除空目录
os.remove("file.txt")            # 删除文件

# 重命名
os.rename("old.txt", "new.txt")

# 判断
print(os.path.exists("file.txt"))   # 是否存在
print(os.path.isfile("file.txt"))   # 是否是文件
print(os.path.isdir("dir"))         # 是否是目录
```

### 2.2 路径操作

```python
import os

# 路径拼接（跨平台安全）
path = os.path.join("d:", "test", "file.txt")
print(path)  # d:\test\file.txt（Windows）

# 获取文件名和目录
full_path = "d:/test/file.txt"
print(os.path.basename(full_path))   # file.txt
print(os.path.dirname(full_path))    # d:/test

# 拆分文件名和扩展名
print(os.path.splitext("file.txt"))  # ('file', '.txt')

# 获取文件大小（字节）
print(os.path.getsize("file.txt"))

# 绝对路径
print(os.path.abspath("file.txt"))
```

### 2.3 环境变量和系统信息

```python
import os

# 获取环境变量
print(os.environ.get("PATH"))
print(os.environ.get("USERNAME"))

# 执行系统命令
os.system("echo Hello")

# 获取操作系统信息
print(os.name)  # nt=Windows, posix=Linux/Mac
```

## 四、JSON 数据 — json 模块

### 4.1 什么是 JSON

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，常用于 API 接口数据传输、配置文件等。

Python 和 JSON 类型对应：
| Python | JSON |
|--------|------|
| dict | object |
| list, tuple | array |
| str | string |
| int, float | number |
| True / False | true / false |
| None | null |

### 4.2 序列化（Python → JSON）

```python
import json

data = {
    "name": "小明",
    "age": 20,
    "score": [85, 92, 78],
    "is_pass": True
}

# 转为 JSON 字符串
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)

# 写入文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

参数说明：
- `ensure_ascii=False` — 保留中文字符（不转成 \uXXXX）
- `indent=2` — 缩进 2 空格，格式化输出

### 4.3 反序列化（JSON → Python）

```python
import json

# 从字符串解析
json_str = '{"name": "小明", "age": 20}'
data = json.loads(json_str)
print(data["name"])   # 小明
print(data["age"])    # 20

# 从文件读取
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
print(data)
```

## 五、正则表达式 — re 模块

### 5.1 什么是正则表达式

正则表达式是用来匹配字符串的强大工具，可以用来验证格式、查找替换、提取信息等。

### 5.2 常用匹配规则

| 符号 | 含义 | 示例 |
|------|------|------|
| `.` | 任意字符（除换行） | `a.c` 匹配 abc, adc |
| `*` | 前一个字符出现 0 次或多次 | `ab*c` 匹配 ac, abc, abbc |
| `+` | 前一个字符出现 1 次或多次 | `ab+c` 匹配 abc, abbc |
| `?` | 前一个字符出现 0 次或 1 次 | `ab?c` 匹配 ac, abc |
| `{n}` | 前一个字符出现 n 次 | `a{3}` 匹配 aaa |
| `{n,m}` | 前一个字符出现 n 到 m 次 | `a{2,4}` 匹配 aa, aaa, aaaa |
| `^` | 字符串开头 | `^hello` |
| `$` | 字符串结尾 | `world$` |
| `[abc]` | 字符集，匹配其中任意一个 | `[aeiou]` 匹配元音 |
| `[^abc]` | 否定字符集 | `[^0-9]` 匹配非数字 |
| `\d` | 数字，等价于 [0-9] | `\d+` 匹配数字串 |
| `\w` | 字母数字下划线 | `\w+` 匹配单词 |
| `\s` | 空白字符（空格、制表符等） | |
| `\|` | 或 | `cat\|dog` 匹配 cat 或 dog |
| `()` | 分组 | `(ab)+` 匹配 ab, abab |

### 5.3 常用方法

```python
import re

# 1. match — 从开头匹配
result = re.match(r"\d+", "123abc")
print(result.group())  # 123

# 2. search — 搜索第一个匹配项
result = re.search(r"\d+", "abc123def456")
print(result.group())  # 123

# 3. findall — 找到所有匹配项（返回列表）
results = re.findall(r"\d+", "abc123def456")
print(results)  # ['123', '456']

# 4. sub — 替换
new_str = re.sub(r"\d+", "###", "abc123def456")
print(new_str)  # abc###def###

# 5. split — 分割
parts = re.split(r"[,; ]", "a,b;c d")
print(parts)  # ['a', 'b', 'c', 'd']
```

### 5.4 常用正则示例

```python
import re

# 验证邮箱
pattern = r"^[\w.-]+@[\w.-]+\.\w+$"
print(re.match(pattern, "test@example.com"))  # 匹配

# 验证手机号（中国大陆）
pattern = r"^1[3-9]\d{9}$"
print(re.match(pattern, "13812345678"))  # 匹配

# 提取 HTML 中的内容
html = "<title>网页标题</title>"
result = re.search(r"<title>(.*?)</title>", html)
print(result.group(1))  # 网页标题

# 替换多个空格为一个
text = "hello    world   !"
clean = re.sub(r"\s+", " ", text)
print(clean)  # hello world !
```

## 六、随机数 — random 模块

### 6.1 生成随机数

```python
import random

# 随机整数（包含两端）
print(random.randint(1, 10))    # 1 到 10 之间的整数

# 随机浮点数 [0, 1)
print(random.random())          # 0 到 1 之间的小数

# 指定范围的随机浮点数
print(random.uniform(1.5, 3.5))  # 1.5 到 3.5 之间
```

### 6.2 随机选择

```python
import random

fruits = ["苹果", "香蕉", "橘子", "草莓", "蓝莓"]

# 随机选一个
print(random.choice(fruits))

# 随机选多个（不重复）
print(random.sample(fruits, 3))

# 随机选多个（可重复）
print(random.choices(fruits, k=3))

# 打乱列表（原地修改）
random.shuffle(fruits)
print(fruits)
```

### 6.3 随机种子

```python
import random

# 设置种子后，随机序列是固定的（可复现）
random.seed(42)
print(random.randint(1, 100))  # 每次运行都一样
```

## 七、数学函数 — math 模块

### 7.1 常用数学函数

```python
import math

# 常数
print(math.pi)      # 圆周率 π
print(math.e)       # 自然常数 e

# 基本运算
print(math.sqrt(16))      # 4.0 平方根
print(math.pow(2, 3))     # 8.0 幂运算
print(math.abs(-5))       # 5 绝对值

# 取整
print(math.ceil(3.2))     # 4 向上取整
print(math.floor(3.8))    # 3 向下取整

# 三角函数
print(math.sin(math.pi/2))   # 1.0
print(math.cos(math.pi))     # -1.0

# 对数
print(math.log(100, 10))    # 2.0 以10为底
print(math.log(math.e))     # 1.0 自然对数

# 阶乘
print(math.factorial(5))    # 120
```

## 八、高级容器 — collections 模块

### 8.1 Counter — 计数器

```python
from collections import Counter

text = "hello world"
counter = Counter(text)
print(counter)  # Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ...})

# 出现次数最多的前 n 个
print(counter.most_common(2))  # [('l', 3), ('o', 2)]

# 统计列表
fruits = ["苹果", "香蕉", "苹果", "橘子", "香蕉", "苹果"]
print(Counter(fruits))
```

### 8.2 defaultdict — 带默认值的字典

```python
from collections import defaultdict

# 普通字典访问不存在的 key 会报错
# defaultdict 会自动创建默认值

# 默认值是 0（int）
d = defaultdict(int)
d["a"] += 1
d["b"] += 2
print(d)  # {'a': 1, 'b': 2}

# 默认值是列表
d = defaultdict(list)
d["fruits"].append("苹果")
d["fruits"].append("香蕉")
print(d)  # {'fruits': ['苹果', '香蕉']}
```

### 8.3 deque — 双端队列

```python
from collections import deque

d = deque([1, 2, 3])

# 两端操作都是 O(1)，比 list 高效
d.append(4)       # 右端加
d.appendleft(0)   # 左端加
print(d)          # deque([0, 1, 2, 3, 4])

d.pop()           # 右端删
d.popleft()       # 左端删
print(d)          # deque([1, 2, 3])
```

## 十、常见问题

**Q**: `datetime` 和 `time` 模块有什么区别？
**A**: `time` 更底层，主要处理时间戳（秒数）；`datetime` 更面向对象，处理日期时间更方便。大多数情况用 `datetime` 就够了。

**Q**: 正则表达式太难记了，怎么办？
**A**: 不用硬背。常用的记住几个（`\d`, `\w`, `+`, `*`, `.*?`），其他的用到再查。可以用在线工具测试，比如 regex101.com。

**Q**: `json.dumps` 输出中文乱码怎么办？
**A**: 加上 `ensure_ascii=False` 参数，同时文件保存时用 `encoding="utf-8"`。
