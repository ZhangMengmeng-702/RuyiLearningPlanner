## 一、什么是面向对象

### 1.1 从生活中理解

想象你要设计一个"学生管理系统"：

**面向过程的思路**：
- 写一个函数 `add_student()` 添加学生
- 写一个函数 `print_student()` 打印学生信息
- 写一个函数 `cal_score()` 计算总分
- 数据（学生信息）和函数是分开的

**面向对象的思路**：
- 设计一个"学生"模板（类）
- 每个学生都是这个模板的一个实例（对象）
- 学生自己知道自己的名字、分数（属性）
- 学生自己可以自我介绍、计算总分（方法）
- 数据和功能打包在一起

### 1.2 类和对象

| 概念 | 生活中的例子 | Python 中 |
|------|:-----------:|:---------:|
| **类（Class）** | 设计图纸、模具、模板 | `class Student:` |
| **对象（Object）** | 按图纸造出来的具体东西 | `s = Student()` |

类是抽象的模板，对象是具体的实例。

一个类可以创建无数个对象：
```
Student 类（模板）
   ├─→ 张三 对象
   ├─→ 李四 对象
   ├─→ 王五 对象
   └─→ ...
```

### 1.3 为什么要用面向对象

| 优点 | 说明 |
|------|------|
| **代码复用** | 写一次类，创建无数对象 |
| **封装性** | 数据和方法打包，外部不需要知道内部细节 |
| **可维护性** | 修改一个类，所有对象都更新 |
| **更符合人类思维** | 把事物看作有属性和行为的对象 |

## 二、定义类和创建对象

### 2.1 最简单的类

```python
# 定义一个学生类
class Student:
    pass  # 空类，先占位

# 创建对象
s1 = Student()
s2 = Student()

print(type(s1))  # <class '__main__.Student'>
print(s1 is s2)  # False，两个不同的对象
```

> **命名规范**：类名用大驼峰命名法（每个单词首字母大写），比如 `Student`, `BankAccount`, `MyClass`

### 2.2 添加属性

属性就是对象的特征/数据。

```python
s1 = Student()
s1.name = "张三"   # 给 s1 添加 name 属性
s1.age = 18        # 给 s1 添加 age 属性
s1.score = 95      # 给 s1 添加 score 属性

s2 = Student()
s2.name = "李四"
s2.age = 19
s2.score = 88

print(s1.name)  # 张三
print(s2.name)  # 李四
```

但这样每个对象都要手动加属性，太麻烦了。有没有更好的方法？有——构造方法。

## 三、构造方法 `__init__`

### 3.1 什么是构造方法

构造方法是创建对象时**自动调用**的方法，用来初始化对象的属性。

名字固定为 `__init__`（前后各两个下划线）。

```python
class Student:
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score

# 创建对象时传入参数
s1 = Student("张三", 18, 95)
s2 = Student("李四", 19, 88)

print(s1.name)  # 张三
print(s2.name)  # 李四
print(s1.age)   # 18
```

**执行过程**：
1. `Student("张三", 18, 95)` 创建一个新对象
2. 自动调用 `__init__` 方法
3. `self` 就是刚创建的那个新对象
4. 给 `self` 添加 name、age、score 属性
5. 返回这个对象，赋值给 `s1`

### 3.2 `self` 到底是什么？

`self` 代表**当前对象本身**。

你可以这样理解：
- 类是工厂的模具
- `self` 就是正在被生产的那个零件
- 在模具里操作 `self`，就是给正在生产的零件加特征

```python
class Student:
    def __init__(self, name):
        self.name = name  # 给"我自己"加 name 属性
    
    def say_hello(self):
        print(f"你好，我是{self.name}")  # 说"我自己"的名字

s1 = Student("张三")
s2 = Student("李四")

s1.say_hello()  # 你好，我是张三
s2.say_hello()  # 你好，我是李四
```

调用 `s1.say_hello()` 时，`self` 就是 `s1`；
调用 `s2.say_hello()` 时，`self` 就是 `s2`。

> **注意**：`self` 只是约定俗成的名字，你叫它 `this` 或 `me` 也行，但千万别改——别人看不懂。

## 四、方法

### 4.1 什么是方法

方法就是类里面定义的函数，描述对象能做什么。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
    
    # 方法：自我介绍
    def introduce(self):
        print(f"我叫{self.name}，分数是{self.score}")
    
    # 方法：判断是否及格
    def is_passed(self):
        return self.score >= 60

s = Student("张三", 85)
s.introduce()       # 我叫张三，分数是85
print(s.is_passed()) # True
```

### 4.2 方法 vs 函数

| 区别 | 函数 | 方法 |
|------|:----:|:----:|
| 定义位置 | 独立的 | 写在类里面 |
| 调用方式 | `func()` | `obj.method()` |
| 第一个参数 | 没有特殊要求 | 必须有 `self` |
| 和数据的关系 | 和数据分离 | 和属性（数据）打包在一起 |

### 4.3 方法可以修改属性

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
    
    def deposit(self, amount):
        self.balance += amount
        print(f"存入 {amount} 元，余额 {self.balance} 元")
    
    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            print(f"取出 {amount} 元，余额 {self.balance} 元")
        else:
            print("余额不足")

account = BankAccount("张三", 1000)
account.deposit(500)   # 存入 500 元，余额 1500 元
account.withdraw(200)  # 取出 200 元，余额 1300 元
```

## 五、封装

### 5.1 什么是封装

封装就是：**把数据藏起来，只暴露必要的接口**。

为什么要封装？
- 防止外部随意修改数据，保证数据安全
- 外部不需要知道内部实现细节，用起来简单
- 内部改了不影响外部使用

### 5.2 私有属性

Python 中，**双下划线开头**的属性是私有属性，外部不能直接访问。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.__score = score  # 私有属性

s = Student("张三", 85)
print(s.name)      # 可以访问
print(s.__score)   # 报错！AttributeError
```

### 5.3 getter 和 setter

私有属性虽然外部不能直接访问，但可以通过方法来获取和修改：

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.__score = score
    
    # 获取分数
    def get_score(self):
        return self.__score
    
    # 设置分数（可以加验证逻辑）
    def set_score(self, score):
        if 0 <= score <= 100:
            self.__score = score
        else:
            print("分数必须在 0-100 之间")

s = Student("张三", 85)
print(s.get_score())  # 85

s.set_score(95)
print(s.get_score())  # 95

s.set_score(120)      # 分数必须在 0-100 之间（不会修改）
```

**好处**：在 `set_score` 里可以加验证逻辑，保证数据合法。

### 5.4 私有方法

方法也可以私有（双下划线开头）：

```python
class Calculator:
    def __init__(self):
        self.result = 0
    
    def add(self, num):
        self.result += num
        self.__log(f"加了 {num}")
        return self.result
    
    # 私有方法，外部不能调用
    def __log(self, message):
        print(f"[日志] {message}，当前结果：{self.result}")

c = Calculator()
c.add(10)   # [日志] 加了 10，当前结果：10
c.__log()   # 报错！私有方法外部不能调用
```

## 六、类属性和类方法

### 6.1 类属性

类属性是属于**类**的，所有对象共享一份。

```python
class Student:
    school = "某某大学"  # 类属性，所有学生共享
    
    def __init__(self, name):
        self.name = name  # 实例属性，每个对象自己的

s1 = Student("张三")
s2 = Student("李四")

print(s1.school)  # 某某大学
print(s2.school)  # 某某大学
print(Student.school)  # 某某大学（通过类访问）

# 修改类属性
Student.school = "新大学"
print(s1.school)  # 新大学（所有对象都变了）
print(s2.school)  # 新大学
```

| 类型 | 定义方式 | 访问方式 | 属于谁 |
|------|---------|---------|:------:|
| 实例属性 | `self.xxx` | `对象.xxx` | 每个对象各一份 |
| 类属性 | 类里面直接写 | `类.xxx` 或 `对象.xxx` | 类只有一份，所有对象共享 |

### 6.2 类方法

类方法用 `@classmethod` 装饰器，第一个参数是 `cls`（代表类本身）：

```python
class Student:
    school = "某某大学"
    
    def __init__(self, name):
        self.name = name
    
    @classmethod
    def change_school(cls, new_school):
        cls.school = new_school
        print(f"学校改为：{new_school}")

Student.change_school("新大学")  # 通过类调用
print(Student.school)             # 新大学
```

> **什么时候用类方法？** 当方法需要访问或修改类属性时。

### 6.3 静态方法

静态方法用 `@staticmethod` 装饰器，不需要 `self` 也不需要 `cls`：

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b
    
    @staticmethod
    def is_prime(n):
        if n < 2:
            return False
        for i in range(2, int(n ** 0.5) + 1):
            if n % i == 0:
                return False
        return True

print(MathUtils.add(3, 5))        # 8
print(MathUtils.is_prime(17))     # True
```

> **什么时候用静态方法？** 方法既不需要访问实例属性，也不需要访问类属性，只是恰好放在类里面的工具函数。

## 七、面向对象设计练习

### 7.1 设计一个"矩形"类

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        """计算面积"""
        return self.width * self.height
    
    def perimeter(self):
        """计算周长"""
        return 2 * (self.width + self.height)
    
    def is_square(self):
        """是不是正方形"""
        return self.width == self.height

r = Rectangle(4, 6)
print(r.area())       # 24
print(r.perimeter())  # 20
print(r.is_square())  # False
```

### 7.2 设计一个"点"类

```python
import math

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def distance_to(self, other):
        """计算到另一个点的距离"""
        dx = self.x - other.x
        dy = self.y - other.y
        return math.sqrt(dx ** 2 + dy ** 2)

p1 = Point(0, 0)
p2 = Point(3, 4)
print(p1.distance_to(p2))  # 5.0
```

## 八、常见问题

**Q**: `self` 必须叫 `self` 吗？
**A**: 不是，你可以叫它任何名字，比如 `this`、`me`。但所有人都用 `self`，改了别人看不懂。强烈建议保持 `self`。

**Q**: 构造方法 `__init__` 有返回值吗？
**A**: 没有（或者说只能返回 `None`）。它的作用是初始化对象，不是返回东西。对象是 `类名()` 自动创建并返回的。

**Q**: 一个类可以有多个构造方法吗？
**A**: Python 不支持。如果写了多个 `__init__`，只有最后一个生效。可以通过默认参数实现类似效果。

**Q**: 私有属性真的完全不能访问吗？
**A**: Python 的私有是"名字改写"（name mangling），不是真正的私有。`_Student__score` 还是能访问，但强烈不建议这么做。

**Q**: 面向对象和面向过程哪个好？
**A**: 没有绝对的好坏。简单的小脚本用面向过程更简洁；复杂的、需要扩展维护的项目用面向对象更合适。数据分析中很多时候两种混着用。
