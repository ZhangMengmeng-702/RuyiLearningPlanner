## 学习目标

学会读写文件，能用 try/except 处理程序中的异常。

## 核心概念

### 文件读写
```python
# 写文件
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("Hello World\\n")

# 读文件
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()
    for line in f:          # 逐行读
        print(line.strip())
```

### 异常处理
```python
try:
    num = int(input("输入一个数字: "))
    result = 10 / num
except ValueError:
    print("那不是数字！")
except ZeroDivisionError:
    print("不能除以零！")
else:
    print(f"结果是 {result}")
finally:
    print("无论如何都会执行")
```
