## 学习目标

完成本章后，你能：
1. 用 `if/elif/else` 写条件判断
2. 用 `for` 和 `while` 写循环
3. 理解 `break` 和 `continue` 的作用
4. 能写嵌套的条件和循环

## 核心概念

### 条件判断
```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### for 循环
```python
for i in range(5):
    print(i)  # 输出 0,1,2,3,4

for fruit in ["苹果", "香蕉", "橘子"]:
    print(fruit)
```

### while 循环
```python
count = 0
while count < 3:
    print(f"第{count+1}次")
    count += 1
```

## 常见问题

**Q**: `range(5)` 是从 0 开始还是从 1 开始？
**A**: 从 0 开始，到 4 结束。`range(5)` = 0, 1, 2, 3, 4。

**Q**: `break` 和 `continue` 有什么区别？
**A**: `break` 跳出整个循环，`continue` 跳过本次循环的剩余部分进入下一次。
