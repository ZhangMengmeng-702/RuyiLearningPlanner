## 核心概念

### Matplotlib 基础

```python
import matplotlib.pyplot as plt
import numpy as np

# 基本折线图
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y, marker='o', linestyle='-', color='blue', label='y=2x')
plt.title("折线图示例")
plt.xlabel("X 轴")
plt.ylabel("Y 轴")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### 柱状图

```python
categories = ["苹果", "香蕉", "橘子", "草莓"]
values = [30, 45, 25, 50]

plt.bar(categories, values, color=['red', 'yellow', 'orange', 'pink'])
plt.title("水果销量")
plt.ylabel("销量（kg）")

# 在柱子上标数值
for i, v in enumerate(values):
    plt.text(i, v + 1, str(v), ha='center')
plt.show()
```

### 散点图

```python
x = np.random.randn(100)
y = np.random.randn(100)
colors = np.random.rand(100)
sizes = np.random.rand(100) * 200

plt.scatter(x, y, c=colors, s=sizes, alpha=0.6)
plt.title("散点图")
plt.xlabel("X")
plt.ylabel("Y")
plt.colorbar(label="颜色值")
plt.show()
```

### Seaborn 进阶图表

```python
import seaborn as sns

# Seaborn 自带示例数据集
tips = sns.load_dataset("tips")  # 餐厅小费数据

# 箱线图——查看分布和异常值
sns.boxplot(x="day", y="total_bill", data=tips)
plt.title("各天消费金额分布")
plt.show()

# 热力图——相关性矩阵
corr = tips.select_dtypes(include=[np.number]).corr()
sns.heatmap(corr, annot=True, cmap="coolwarm", fmt=".2f")
plt.title("数值特征相关性热力图")
plt.show()

# 分布直方图
sns.histplot(tips["total_bill"], bins=30, kde=True)
plt.title("消费金额分布")
plt.show()

# 分类散点图（蜂群图）
sns.swarmplot(x="day", y="total_bill", hue="sex", data=tips)
plt.show()
```

### 子图布局

```python
fig, axes = plt.subplots(2, 2, figsize=(12, 8))

axes[0, 0].plot(x, y)
axes[0, 0].set_title("折线图")

axes[0, 1].bar(categories, values)
axes[0, 1].set_title("柱状图")

axes[1, 0].scatter(np.random.randn(50), np.random.randn(50))
axes[1, 0].set_title("散点图")

axes[1, 1].hist(np.random.randn(1000), bins=30)
axes[1, 1].set_title("直方图")

plt.tight_layout()
plt.show()
```


## 常见问题

**Q**: `plt.show()` 后图表一闪而过怎么办？
**A**: 在 Jupyter Notebook 中会直接显示。在脚本中运行后，脚本结束窗口自动关闭。可以先调用 `plt.savefig()` 保存图片。

**Q**: Seaborn 和 Matplotlib 的关系是什么？
**A**: Seaborn 基于 Matplotlib，提供了更高层的 API。Seaborn 的图表本质上也是 Matplotlib 对象，可以用 `plt` 的 API 进一步修改。

**Q**: 中文字体显示为方框怎么办？
**A**: 显式设置中文字体：
```python
plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei"]
plt.rcParams["axes.unicode_minus"] = False  # 解决负号显示问题
```
