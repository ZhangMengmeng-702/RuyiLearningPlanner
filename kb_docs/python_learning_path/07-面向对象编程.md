## 核心概念

### 定义类与创建对象

```python
class Student:
    def __init__(self, name: str, age: int, score: float):
        self.name = name      # 属性
        self.age = age
        self.score = score

    def introduce(self) -> str:   # 方法
        return f"我叫{self.name}，今年{self.age}岁"

    def is_pass(self) -> bool:
        return self.score >= 60

# 创建对象
s1 = Student("小明", 20, 85)
print(s1.introduce())   # 我叫小明，今年20岁
print(s1.is_pass())     # True
```

### 继承

```python
class GraduateStudent(Student):
    def __init__(self, name, age, score, thesis_title):
        super().__init__(name, age, score)  # 调用父类构造
        self.thesis_title = thesis_title

    def introduce(self):  # 重写父类方法
        return f"我是研究生{self.name}，研究{self.thesis_title}"
```

### 封装（私有属性）

```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance  # 双下划线=私有

    def withdraw(self, amount):
        if amount <= self.__balance:
            self.__balance -= amount
            return True
        return False

    def get_balance(self):  # 公开的访问方法
        return self.__balance
```

## 常见问题

**Q**: `self` 是什么？为什么每个方法都要写它？
**A**: `self` 代表实例本身。调用 `s1.introduce()` 时，Python 会自动把 `s1` 作为第一个参数传给 `self`。所以方法定义时第一个参数必须是 `self`（名字可以改但约定如此）。

**Q**: `__init__` 是构造函数吗？
**A**: 严格来说是初始化方法（initializer），不是构造函数（constructor）。对象已经创建后才调 `__init__` 来初始化属性。真正负责创建的是 `__new__`，但你几乎不需要碰它。
