## 学习目标

完成本章后，你能：
1. 理解什么是变量、如何给变量赋值
2. 掌握 Python 的三种基本数据类型：int、float、str
3. 会用 `type()` 查看变量类型
4. 会用 `print()` 输出、`input()` 输入

## 核心概念

### 变量赋值
```python
name = "小明"     # 字符串
age = 20          # 整数
height = 1.75     # 浮点数
```

### 基本数据类型
- `int` — 整数：`1`, `100`, `-5`
- `float` — 浮点数：`3.14`, `-0.5`, `2.0`
- `str` — 字符串：`"Hello"`, `'你好'`

### 输入输出
```python
print("Hello World")
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

## 练习题

1. 创建一个变量 `my_name` 存储你的名字，`my_age` 存储年龄，打印它们
2. 用 `type()` 检查 `3.14` 和 `"3.14"` 的类型，你发现了什么？
3. 写一个程序：让用户输入两个数字，打印它们的和

## 常见问题

**Q**: 变量名可以以数字开头吗？
**A**: 不可以。变量名只能以字母或下划线开头。

**Q**: `input()` 返回的是什么类型？
**A**: 字符串。如果需要数字，要用 `int()` 或 `float()` 转换。
