## 核心概念

### 字典基础

字典（Dict）是**键值对**的无序集合，用大括号表示。键必须是唯一的、不可变的（字符串、数字、元组等）。

```python
student = {
    "name": "小明",
    "age": 20,
    "score": 88,
    "city": "北京"
}
```

### 字典的访问与修改

```python
student = {"name": "小明", "age": 20, "score": 88}

# 访问
print(student["name"])      # 小明
print(student.get("age"))   # 20（get 方法更安全，key 不存在时返回 None）
print(student.get("gender", "未知"))  # 第二个参数是默认值

# 修改/添加
student["age"] = 21              # 修改
student["gender"] = "男"         # 新增（key 不存在就添加）

# 删除
del student["city"]              # 删除指定键值对
age = student.pop("age")         # 删除并返回值
```

### 字典的遍历

```python
student = {"name": "小明", "age": 20, "score": 88}

# 遍历键
for key in student:
    print(key)

# 遍历值
for value in student.values():
    print(value)

# 遍历键值对（最常用）
for k, v in student.items():
    print(f"{k}: {v}")
```

### 字典的常用操作

```python
d = {"a": 1, "b": 2}

print(len(d))           # 键值对数量
print("a" in d)         # 判断键是否存在
print(d.keys())         # 所有键
print(d.values())       # 所有值
print(d.items())        # 所有键值对

d.update({"c": 3, "d": 4})  # 合并另一个字典
d.clear()               # 清空
```

### 字典推导式

```python
# 基本形式：{key: value for 变量 in 可迭代对象}
squares = {x: x**2 for x in range(5)}
print(squares)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 带条件
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}
print(even_squares)  # {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

# 字典键值反转
original = {"a": 1, "b": 2, "c": 3}
reversed_dict = {v: k for k, v in original.items()}
print(reversed_dict)  # {1: 'a', 2: 'b', 3: 'c'}
```

### 集合基础

集合（Set）是**无序、不重复**的元素集合，用大括号表示（和字典区分：字典是键值对，集合是单元素）。

```python
numbers = {1, 2, 2, 3, 3, 3}
print(numbers)  # {1, 2, 3}（自动去重）

# 创建空集合要用 set()，不能用 {}（{} 是空字典）
empty_set = set()
```

### 集合的常用操作

```python
s = {1, 2, 3}

# 添加
s.add(4)
s.update([5, 6])

# 删除
s.remove(3)    # 删除指定元素，不存在则报错
s.discard(10)  # 删除指定元素，不存在也不报错
s.pop()        # 随机删除并返回一个元素

# 判断
print(2 in s)
print(len(s))
```

### 集合运算

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)    # 交集：{3, 4}
print(a | b)    # 并集：{1, 2, 3, 4, 5, 6}
print(a - b)    # 差集：{1, 2}（a 有 b 没有）
print(a ^ b)    # 对称差：{1, 2, 5, 6}（不同时在两个集合里）

# 子集、超集
print({1, 2}.issubset(a))     # True
print(a.issuperset({1, 2}))   # True
```

**集合的典型应用场景**：
- 去重：`list(set([1,2,2,3]))`
- 成员判断：`x in s`（比列表快很多）
- 交集/并集/差集运算

### 四种数据结构对比

| 类型 | 有序? | 可变? | 重复? | 表示方式 | 典型场景 |
|------|:-----:|:-----:|:-----:|---------|---------|
| 列表 List | ✅ | ✅ | ✅ | `[]` | 有序序列 |
| 元组 Tuple | ✅ | ❌ | ✅ | `()` | 不可变数据 |
| 字典 Dict | ❌ | ✅ | key 唯一 | `{k:v}` | 键值对映射 |
| 集合 Set | ❌ | ✅ | ❌ | `{}` | 去重、集合运算 |

## 常见问题

**Q**: 字典的 key 可以用列表吗？
**A**: 不可以。字典的 key 必须是不可变类型（字符串、数字、元组）。列表是可变的，不能作为 key。

**Q**: 集合是有序的吗？
**A**: Python 3.7+ 的字典是有序的（按插入顺序），但集合仍然是无序的。不要依赖集合的顺序。

**Q**: 什么时候用字典，什么时候用列表？
**A**: 需要通过 key 快速查找值时用字典（比如学生信息通过名字查分数）；需要有序序列、通过索引访问时用列表。
