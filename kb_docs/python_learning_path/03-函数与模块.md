## 学习目标

完成本章后，你能：
1. 用 `def` 定义函数
2. 理解参数传递和返回值
3. 理解变量的作用域（局部 vs 全局）
4. 用 `import` 导入标准库模块

## 核心概念

### 函数定义
```python
def greet(name):
    return f"你好，{name}！"

result = greet("小明")
print(result)  # "你好，小明！"
```

### 参数类型
```python
def add(a, b=0):      # b 有默认值
    return a + b

add(3, 4)    # 7
add(3)       # 3（b 用默认值 0）
```

### 模块导入
```python
import math
import random as rnd
from datetime import datetime

print(math.sqrt(16))          # 4.0
print(rnd.randint(1, 10))    # 随机 1-10
print(datetime.now())         # 当前时间
```

## 常见问题

**Q**: 函数内修改全局变量为什么无效？
**A**: 函数内赋值会创建局部变量。要修改全局变量需用 `global` 关键字声明。

**Q**: `import math` 和 `from math import sqrt` 有什么区别？
**A**: 前者使用时需要 `math.sqrt()`，后者可以直接 `sqrt()`。后者更简洁但可能引起名字冲突。
