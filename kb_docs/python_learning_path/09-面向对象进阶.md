## 一、继承（Inheritance）

### 1.1 什么是继承

继承就是**子类拥有父类的所有属性和方法**，并且可以添加自己的特性。

生活中的例子：
- 动物 → 猫、狗、鸟
- 交通工具 → 汽车、飞机、轮船
- 人 → 学生、老师、工程师

```python
# 父类（基类）
class Animal:
    def __init__(self, name):
        self.name = name
    
    def eat(self):
        print(f"{self.name} 在吃东西")
    
    def sleep(self):
        print(f"{self.name} 在睡觉")

# 子类（派生类）
class Dog(Animal):  # 继承 Animal
    def bark(self):
        print(f"{self.name} 在汪汪叫")

class Cat(Animal):  # 继承 Animal
    def meow(self):
        print(f"{self.name} 在喵喵叫")

dog = Dog("旺财")
dog.eat()    # 旺财 在吃东西（继承自父类）
dog.bark()   # 旺财 在汪汪叫（自己的方法）

cat = Cat("咪咪")
cat.sleep()  # 咪咪 在睡觉（继承自父类）
cat.meow()   # 咪咪 在喵喵叫（自己的方法）
```

**好处**：
- 代码复用：父类写一次，所有子类都能用
- 层次清晰：符合现实世界的分类逻辑
- 易于扩展：新增子类很方便

### 1.2 方法重写（Override）

子类可以**重写**父类的方法，覆盖父类的实现：

```python
class Animal:
    def speak(self):
        print("动物在叫")

class Dog(Animal):
    def speak(self):  # 重写父类方法
        print("汪汪汪！")

class Cat(Animal):
    def speak(self):  # 重写父类方法
        print("喵喵喵～")

dog = Dog()
cat = Cat()

dog.speak()  # 汪汪汪！
cat.speak()  # 喵喵喵～
```

### 1.3 `super()` 调用父类

在子类中调用父类的方法，用 `super()`：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def introduce(self):
        print(f"我叫{self.name}，今年{self.age}岁")

class Student(Person):
    def __init__(self, name, age, grade):
        super().__init__(name, age)  # 调用父类的构造方法
        self.grade = grade           # 子类自己的属性
    
    def introduce(self):
        super().introduce()  # 调用父类的方法
        print(f"我读{self.grade}年级")

s = Student("张三", 15, 9)
s.introduce()
# 输出：
# 我叫张三，今年15岁
# 我读9年级
```

### 1.4 继承层次

可以多层继承：
```python
class Animal:       # 爷爷类
    def eat(self):
        print("吃东西")

class Mammal(Animal):  # 父类
    def give_birth(self):
        print("胎生")

class Dog(Mammal):    # 子类
    def bark(self):
        print("汪汪叫")

dog = Dog()
dog.eat()         # 继承自 Animal
dog.give_birth()  # 继承自 Mammal
dog.bark()        # 自己的方法
```

### 1.5 多继承

一个类可以同时继承多个父类：

```python
class Flyer:
    def fly(self):
        print("我会飞")

class Swimmer:
    def swim(self):
        print("我会游泳")

class Duck(Flyer, Swimmer):  # 多继承
    pass

duck = Duck()
duck.fly()   # 我会飞
duck.swim()  # 我会游泳
```

**多继承的问题**：如果两个父类有同名方法，调用谁的？

Python 使用 **MRO（方法解析顺序）** 算法，从左到右查找：
```python
class A:
    def hello(self):
        print("A 说 hello")

class B:
    def hello(self):
        print("B 说 hello")

class C(A, B):  # 先继承 A，再继承 B
    pass

c = C()
c.hello()  # A 说 hello（左边的优先）

print(C.__mro__)  # 查看方法解析顺序
```

> **建议**：多继承容易混乱，新手尽量少用。可以用「组合」替代多继承。

## 二、多态（Polymorphism）

### 2.1 什么是多态

多态就是**同一个接口，不同的实现**。

```python
class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        print("汪汪汪！")

class Cat(Animal):
    def speak(self):
        print("喵喵喵～")

class Duck(Animal):
    def speak(self):
        print("嘎嘎嘎～")

# 多态：同一个函数，传入不同对象，表现不同
def make_speak(animal):
    animal.speak()

dog = Dog()
cat = Cat()
duck = Duck()

make_speak(dog)   # 汪汪汪！
make_speak(cat)   # 喵喵喵～
make_speak(duck)  # 嘎嘎嘎～
```

**关键点**：
- 不需要判断对象类型，直接调用方法
- 新增一个动物类，`make_speak` 函数不用改
- 符合「开闭原则」：对扩展开放，对修改关闭

### 2.2 Python 的「鸭子类型」

Python 是动态语言，不严格要求继承关系。只要有这个方法，就能用：

```python
class Dog:
    def speak(self):
        print("汪汪汪！")

class Robot:
    def speak(self):
        print("你好，我是机器人")

def make_speak(something):
    something.speak()  # 只要有 speak 方法就行

dog = Dog()
robot = Robot()

make_speak(dog)    # 汪汪汪！
make_speak(robot)  # 你好，我是机器人
```

「鸭子类型」：只要走起来像鸭子、叫起来像鸭子，那它就是鸭子。

## 三、魔术方法（Magic Methods）

### 3.1 什么是魔术方法

魔术方法是 Python 中**前后各有两个下划线**的特殊方法，在特定情况下自动调用。

比如我们已经学过的 `__init__` 就是一个魔术方法。

### 3.2 `__str__` — 对象的字符串表示

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

s = Student("张三", 85)
print(s)  # <__main__.Student object at 0x...> （看不懂）
```

加了 `__str__` 之后：
```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
    
    def __str__(self):
        return f"学生：{self.name}，分数：{self.score}"

s = Student("张三", 85)
print(s)  # 学生：张三，分数：85
```

### 3.3 `__len__` — 长度

```python
class Playlist:
    def __init__(self):
        self.songs = []
    
    def add(self, song):
        self.songs.append(song)
    
    def __len__(self):
        return len(self.songs)

p = Playlist()
p.add("稻香")
p.add("青花瓷")
print(len(p))  # 2
```

### 3.4 比较运算魔术方法

| 方法 | 运算符 | 说明 |
|------|:------:|------|
| `__eq__(self, other)` | `==` | 等于 |
| `__ne__(self, other)` | `!=` | 不等于 |
| `__lt__(self, other)` | `<` | 小于 |
| `__le__(self, other)` | `<=` | 小于等于 |
| `__gt__(self, other)` | `>` | 大于 |
| `__ge__(self, other)` | `>=` | 大于等于 |

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
    
    def __eq__(self, other):
        return self.score == other.score
    
    def __lt__(self, other):
        return self.score < other.score

s1 = Student("张三", 85)
s2 = Student("李四", 90)
s3 = Student("王五", 85)

print(s1 < s2)   # True
print(s1 == s3)  # True（分数相同，就算相等）

# 有了比较方法，还可以排序！
students = [s2, s1, s3]
students.sort()  # 按分数升序
for s in students:
    print(s.name, s.score)
```

### 3.5 算术运算魔术方法

| 方法 | 运算符 | 说明 |
|------|:------:|------|
| `__add__(self, other)` | `+` | 加法 |
| `__sub__(self, other)` | `-` | 减法 |
| `__mul__(self, other)` | `*` | 乘法 |
| `__truediv__(self, other)` | `/` | 除法 |

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    def __str__(self):
        return f"({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)  # (4, 6)
```

### 3.6 `__getitem__` 和 `__setitem__` — 像列表一样访问

```python
class MyList:
    def __init__(self):
        self.data = []
    
    def __getitem__(self, index):
        return self.data[index]
    
    def __setitem__(self, index, value):
        self.data[index] = value
    
    def __len__(self):
        return len(self.data)
    
    def append(self, value):
        self.data.append(value)

mylist = MyList()
mylist.append(10)
mylist.append(20)
mylist.append(30)

print(mylist[0])   # 10
mylist[1] = 99
print(mylist[1])   # 99
print(len(mylist)) # 3
```

### 3.7 `__call__` — 让对象像函数一样被调用

```python
class Adder:
    def __init__(self, base):
        self.base = base
    
    def __call__(self, x):
        return self.base + x

add5 = Adder(5)
print(add5(10))  # 15（像函数一样调用对象）
print(add5(20))  # 25
```

## 四、`@property` 装饰器

### 4.1 为什么需要 property

传统的 getter/setter 写法：
```python
class Student:
    def __init__(self, name):
        self.__name = name
    
    def get_name(self):
        return self.__name
    
    def set_name(self, name):
        if name:
            self.__name = name

s = Student("张三")
print(s.get_name())  # 调用方法，麻烦
```

用 `@property` 可以**像访问属性一样访问方法**：

```python
class Student:
    def __init__(self, name):
        self.__name = name
    
    @property
    def name(self):
        """获取名字"""
        return self.__name
    
    @name.setter
    def name(self, value):
        """设置名字（带验证）"""
        if value and value.strip():
            self.__name = value
        else:
            raise ValueError("名字不能为空")

s = Student("张三")
print(s.name)    # 张三（像属性一样访问）
s.name = "李四"  # 像属性一样设置
print(s.name)    # 李四
```

**好处**：
- 用起来像属性一样简单
- 但实际上有方法的逻辑（可以加验证）
- 代码更优雅

### 4.2 只读属性

只加 `@property`，不加 `@xxx.setter`，就是只读的：

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius
    
    @property
    def area(self):
        """面积是计算出来的，只读"""
        import math
        return math.pi * self.radius ** 2

c = Circle(5)
print(c.area)  # 78.5398...
c.area = 100   # 报错！只读，不能赋值
```

## 五、常用设计模式（了解）

### 5.1 单例模式（Singleton）

保证一个类只有一个实例。

```python
class Singleton:
    _instance = None
    
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True，同一个对象
```

**使用场景**：配置管理、日志记录器、数据库连接池等。

### 5.2 工厂模式（Factory）

用工厂函数/类来创建对象，而不是直接 `new`。

```python
class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        print("汪汪汪")

class Cat(Animal):
    def speak(self):
        print("喵喵喵")

# 工厂
class AnimalFactory:
    @staticmethod
    def create_animal(animal_type):
        if animal_type == "dog":
            return Dog()
        elif animal_type == "cat":
            return Cat()
        else:
            raise ValueError(f"未知动物类型：{animal_type}")

dog = AnimalFactory.create_animal("dog")
cat = AnimalFactory.create_animal("cat")
dog.speak()  # 汪汪汪
cat.speak()  # 喵喵喵
```

**好处**：创建逻辑集中管理，新增类型只加工厂，不改调用处。

### 5.3 策略模式（Strategy）

定义一系列算法，把它们封装起来，并且可以互相替换。

```python
from abc import ABC, abstractmethod

# 策略接口
class DiscountStrategy(ABC):
    @abstractmethod
    def calculate(self, price):
        pass

# 具体策略
class NoDiscount(DiscountStrategy):
    def calculate(self, price):
        return price

class PercentDiscount(DiscountStrategy):
    def __init__(self, percent):
        self.percent = percent
    
    def calculate(self, price):
        return price * self.percent

class FixedDiscount(DiscountStrategy):
    def __init__(self, amount):
        self.amount = amount
    
    def calculate(self, price):
        return max(0, price - self.amount)

# 上下文
class ShoppingCart:
    def __init__(self, strategy):
        self.strategy = strategy
        self.total = 0
    
    def add(self, price):
        self.total += price
    
    def checkout(self):
        return self.strategy.calculate(self.total)

# 使用
cart = ShoppingCart(PercentDiscount(0.8))  # 8折
cart.add(100)
cart.add(200)
print(cart.checkout())  # 240

cart.strategy = FixedDiscount(50)  # 减50
print(cart.checkout())  # 250
```

## 六、抽象类与接口（了解）

### 6.1 抽象基类（ABC）

抽象类不能被实例化，只能被继承。子类必须实现抽象方法。

```python
from abc import ABC, abstractmethod

class Shape(ABC):  # 继承 ABC 就是抽象类
    @abstractmethod
    def area(self):
        pass
    
    @abstractmethod
    def perimeter(self):
        pass

class Rectangle(Shape):
    def __init__(self, w, h):
        self.w = w
        self.h = h
    
    def area(self):
        return self.w * self.h
    
    def perimeter(self):
        return 2 * (self.w + self.h)

# s = Shape()  # 报错！抽象类不能实例化
r = Rectangle(3, 4)
print(r.area())  # 12
```

**作用**：
- 强制子类实现某些方法
- 定义接口规范
- 多态的基础

## 七、常见问题

**Q**: 多继承和组合哪个好？
**A**: 优先用组合。组合更灵活、更容易理解。"has a"（有一个）用组合，"is a"（是一种）用继承。

**Q**: 继承层次太深有什么问题？
**A**: 可读性差、调试困难、修改上层影响面大。建议继承层次不超过 3 层。

**Q**: 魔术方法好多，都要记住吗？
**A**: 不用。常用的记住：`__init__`, `__str__`, `__len__`, `__eq__`。其他的用到再查。

**Q**: 设计模式有必要学吗？
**A**: 了解常见的几种就行。设计模式是「经验总结」，不是「必须遵守的规则」。写得多了自然会体会到。

**Q**: 面向对象一定比面向过程好吗？
**A**: 不是。简单问题用面向过程更直接。数据分析中通常是混合使用——数据处理用面向过程，复杂系统用面向对象。
