## 学习目标

完成本章后，你能：
1. 用 `def` 定义函数
2. 理解参数传递和返回值
3. 理解变量的作用域（局部 vs 全局）
4. 掌握默认参数、关键字参数等参数类型

## 核心概念

### 函数定义
```python
def greet(name):
    return f"你好，{name}！"

result = greet("小明")
print(result)  # "你好，小明！"
```

### 参数类型
```python
def add(a, b=0):      # b 有默认值
    return a + b

add(3, 4)    # 7
add(3)       # 3（b 用默认值 0）
```

### 变量作用域
```python
x = 10  # 全局变量

def func():
    x = 20  # 局部变量，不影响全局
    print(x)

func()  # 20
print(x)  # 10
```

如果要在函数内修改全局变量，需要用 `global` 关键字：
```python
x = 10

def func():
    global x
    x = 20

func()
print(x)  # 20
```

### 多个返回值
```python
def calc(a, b):
    return a + b, a - b, a * b

sum_val, diff, product = calc(10, 3)
print(sum_val, diff, product)  # 13 7 30
```

## 常见问题

**Q**: 函数内修改全局变量为什么无效？
**A**: 函数内赋值会创建局部变量。要修改全局变量需用 `global` 关键字声明。

**Q**: 函数可以返回多个值吗？
**A**: 可以。用逗号分隔多个值，Python 会自动打包成元组返回。接收时可以用多个变量解包。

**Q**: 什么是递归函数？
**A**: 函数自己调用自己就是递归。比如计算阶乘：`factorial(n) = n * factorial(n-1)`。递归一定要有终止条件，否则会死循环。
