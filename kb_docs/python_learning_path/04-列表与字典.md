## 学习目标

掌握 Python 四种核心数据结构：列表、字典、元组、集合，能熟练进行增删改查和推导式操作。

## 核心概念

### 列表
```python
fruits = ["苹果", "香蕉", "橘子"]
fruits.append("草莓")       # 追加
fruits.insert(1, "蓝莓")    # 插入
fruits.remove("香蕉")       # 删除
poped = fruits.pop()        # 弹出末尾
# 列表推导式
squares = [x**2 for x in range(10)]
```

### 字典
```python
student = {"name": "小明", "age": 20, "score": 88}
student["city"] = "北京"             # 新增
student["age"] = 21                  # 修改
for k, v in student.items():         # 遍历
    print(f"{k}: {v}")
```

### 元组 vs 集合
```python
# 元组——不可变
point = (3, 5)
x, y = point                         # 解包

# 集合——去重
numbers = {1, 2, 2, 3, 3, 3}        # {1, 2, 3}
```

## 练习题

1. 用列表推导式生成 1-20 的偶数列表
2. 统计一段文本中每个单词出现的次数（字典）
3. 两个列表取交集、并集、差集（转 set 操作）
