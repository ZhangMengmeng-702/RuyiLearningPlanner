## 学习目标

学会读写文件，能用 try/except 处理程序中的异常。

## 核心概念

### 文件读写
```python
# 写文件
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("Hello World\n")

# 读文件
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 逐行读
with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

**文件打开模式**：
| 模式 | 说明 |
|------|------|
| `r` | 只读（默认） |
| `w` | 写入（覆盖原有内容） |
| `a` | 追加（在末尾添加） |
| `r+` | 读写 |
| `rb` | 二进制读 |
| `wb` | 二进制写 |

### 异常处理
```python
try:
    num = int(input("输入一个数字: "))
    result = 10 / num
except ValueError:
    print("那不是数字！")
except ZeroDivisionError:
    print("不能除以零！")
else:
    print(f"结果是 {result}")
finally:
    print("无论如何都会执行")
```

**常见异常类型**：
- `ValueError` — 值错误（类型转换失败等）
- `TypeError` — 类型错误
- `IndexError` — 索引越界
- `KeyError` — 字典键不存在
- `FileNotFoundError` — 文件不存在
- `ZeroDivisionError` — 除以零

## 常见问题

**Q**: `with` 语句有什么用？
**A**: `with` 语句会自动管理文件的打开和关闭。离开 `with` 块时，文件会自动关闭，不用手动调用 `f.close()`，也避免了忘记关闭文件的问题。

**Q**: 为什么要指定 `encoding="utf-8"`？
**A**: Windows 默认编码可能是 GBK，读写中文文件时容易乱码。显式指定 `encoding="utf-8"` 可以保证跨平台一致性。

**Q**: 异常处理会影响性能吗？
**A**: 正常情况下（不抛异常）几乎没有性能影响。只有当异常真的发生时，才会有额外开销。所以不要用异常来做正常的流程控制。
